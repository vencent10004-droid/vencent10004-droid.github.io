# 코스피·코스닥 실시간 뉴스 분석 자동화

**코스피 시총 상위 400 + 코스닥 상위 200 = 600종목**의 뉴스·공시를 실시간 크롤링하고,
호재/악재 키워드 + 13개 투자유치성 재료 카테고리로 분석해
**다음 거래일 상승 후보**를 선정하는 시스템입니다. 전 과정이 클라우드에서 자동으로 돌아갑니다.

> ⚠️ 키워드 기반 자동 분석 결과일 뿐, 투자 자문이 아닙니다. 투자 판단과 결과의 책임은 본인에게 있습니다.

## 보는 방법

| 방법 | 주소 |
|---|---|
| 📱 휴대폰 앱 (권장) | `https://vencent10004-droid.github.io/kospi/` 접속 → 하단 [📲 앱으로 설치] |
| 🌐 아무 브라우저 | 같은 주소 |

페이지를 열어두면 75초마다 자동 갱신됩니다 (깜빡임 없음).

## 클라우드 자동 운영 (PC 불필요)

- **GitHub Actions**가 평일 07:50~19:58(KST) 동안 상시 루프 실행
- **뉴스·공시**: 5분 주기 병렬 수집 (600종목 약 40초~2분)
- **화면 갱신**: 60초 주기로 data 브랜치에 푸시 → 앱이 최신 커밋을 직접 조회 (체감 1~2분)
- **자동 복구**: watchdog이 15분마다 데이터 신선도 확인, 정체 시 원인 불문 재시작
- 워크플로: `.github/workflows/kospi.yml`(루프) / `watchdog.yml`(감시견)
- 중지하려면: GitHub 저장소 → Actions → 해당 워크플로 → Disable workflow

## 분석 체계

1. **종목 선정**: 시총 상위 600 (ETF·리츠·스팩 등 비기업 제외, [config.py](config.py))
2. **뉴스·공시 수집**: 네이버 금융, 당일 게재분만, 제목에 종목명 포함 기사만 반영
3. **감성 점수**: 호재(+1~2)/악재(-1~-2) 키워드, 같은 키워드는 종목당 3회까지
4. **투자유치성 재료** (+3/카테고리, 즉시 알림): AI빅테크 협력 · 정부 보조금·세제지원 ·
   해외 JV · 대규모 M&A·지분투자 · 국부펀드 · 대규모 수주 · 바이오 기술수출·인허가 ·
   주주환원·밸류업 · 국책사업 · 경영권·지배구조 · 지수 편입 · 디지털자산 · 기술 돌파·독점
5. **경계 재료** (-2, ⚠️ 표시): 보호예수 해제·블록딜 / CB·BW 발행
6. **최종점수** = 뉴스점수 + 당일등락률×0.3 → 시장별 상위 10 후보

같은 내용의 반복 보도는 대표 기사 1건으로 묶고, 뉴스는 종목별 카드로 그룹핑됩니다.
기사 클릭 시 원문(n.news.naver.com), 공시 클릭 시 공시 원문, 종목명 클릭 시 네이버 종목 페이지.

## PC에서 직접 실행 (선택)

```bash
pip install -r requirements.txt
```

- 실시간 모니터링: [start.bat](start.bat) 더블클릭 (로컬 대시보드 http://localhost:8800/)
- 하루치 일괄 분석: `python main.py` (과거 날짜: `python main.py 2026-08-04`)
- 로컬에서 공개 주소 업로드는 기본 꺼짐 (`config.PUBLISH_ENABLED`) — 클라우드와 충돌 방지

## 주요 설정 ([config.py](config.py))

| 설정 | 기본값 | 설명 |
|---|---|---|
| `TOP_N_STOCKS` / `KOSDAQ_TOP_N` | 400 / 200 | 시장별 분석 종목 수 |
| `FETCH_WORKERS` | 8 | 수집 병렬 스레드 |
| `HEATMAP_ENABLED` | False | 히트맵 표시 (True로 되살릴 수 있음) |
| `PICK_COUNT` | 10 | 시장별 추천 종목 수 |
| `MATERIAL_CATEGORIES` / `WARNING_MATERIALS` | - | 재료/경계 카테고리 사전 |
| `POSITIVE_KEYWORDS` / `NEGATIVE_KEYWORDS` | - | 감성 키워드 사전 |

## 구조

```
crawler.py    네이버 금융 크롤링 (종목 목록·뉴스·공시)
analyzer.py   감성 점수 + 재료 감지 + 후보 선정
report.py     대시보드(HTML)·리포트(md)·CSV 생성
realtime.py   로컬 실시간 루프 + 웹서버
cloud_run.py  클라우드 1회 스윕/렌더
cloud_loop.py 클라우드 상시 루프 (뉴스 5분·렌더 60초 병렬)
heatmap.py    세션 인지 실시간 시세 (프리/정규/애프터마켓)
sector.py     종목→업종 매핑 (캐시)
publish.py    (구) 로컬 GitHub 업로드
kospi/        공개 페이지 셸(PWA) + 아이콘
```
